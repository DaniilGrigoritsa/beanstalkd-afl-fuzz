
# Задание
Задача: выбрать проект (реализацию сетевого протокола) и выполнить его фаззинг.

## Проект
Нужно выбрать гитхаб-проект, в котором реализован сетевой протокол.
Проект должен соответствовать следующим критериям:
- C/C++
- не входит в https://github.com/profuzzbench/profuzzbench
- stateful-протокол (очень желательно)
- нет материалов по фаззингу этого проекта в Интернете (фаззинг-обёртки в libfuzzer-стиле из oss-fuzz не считается)
При поиске проекта, возможно, будет полезен прикреплённый список (projects.ods)

## Фаззер
На выбор несколько фаззеров протоколов:
1) AFLNet
2) StateAFL
3) Peach
4) Другие фаззеры тоже допускаются. Но нужно обосновать выбор.

Желательно взять AFL-подобный фаззер (с обратной связью по покрытию).

## План
1. Собрать проект с помощью компиляторов из AFL++
2. Сформировать сценарий (или сценарии) работы приложения, задействующие сразу значительный функционал сервера (или клиента)
3. Реализовать фаззинг во множество процессов одновременно
4. Реализовать пользовательскую мутацию для учёта формата данных (если в фаззере предусмотрена такая возможность)
Сравнить на 30 мин фаззинг с дефолтными мутациями и новой
5. Получить отчёт о покрытии в формате LCOV (HTML)
